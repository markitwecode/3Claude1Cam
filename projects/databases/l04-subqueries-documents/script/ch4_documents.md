[c4.json.1] {json} The usual way to write data in one piece is JSON, short for JavaScript Object Notation. {origin} It began as the part of JavaScript used for writing down data values, and is now a standard of its own. {ada} Here's an example, a record about Ada Lovelace. {braces} Curly braces make an object, a set of key value pairs. {keys} Every key is a string in double quotes, like name, born, and languages.

[c4.json.2] {values} The values come in a few kinds. {string} A string, also in double quotes. {number} A number. {bools} True or false. {null} And null. {array} Square brackets make an array, an ordered list of values, here English, then French. {nested} And a value can itself be another object, like the address, with a city and a country inside.

[c4.json.3] {tree} Since objects and arrays can nest to any depth, a JSON value is really a tree. {root} The whole object is the root. {edges} Each key labels a branch, {leaves} and the plain values hang at the leaves. {inorder} An array's elements hang below it in order, numbered by position. {pause} Keep this tree in mind; later, you'll walk it to reach inside a document.

[c4.json.4] {types} JSON keeps its types few. {numbers} There's just one kind of number. In OCaml, eighteen fifteen and eight point two would have different types, int and float. In JSON, both are simply numbers. {dates} And there's no type for dates. A date, like the day this lecture was given, is written as a string.

[c4.json.5] {everywhere} In return, JSON is everywhere. {web} It carries the messages between apps and servers, and fills configuration files and logs. {python} Every programming language reads it. In Python, an object becomes a dictionary, and an array a list. {xml} X M L once did this job, but it has fallen out of favour. {same} And a database that stores JSON too saves you code converting data on its way to the browser.
