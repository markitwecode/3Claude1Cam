[c5.unwrap.1] {table} A path is a single value. But sometimes you want a table, with one row per step. {rest} That's what the rest of this query does. {convenience} It's a convenience, not something to learn by heart, so let's read it just once, clause by clause.

[c5.unwrap.2] {nodes} Nodes of path is the list of vertices along the path. Cypher calls vertices nodes. {five} Here there are five, alternating between people and movies. {with} The with clause passes that list on to the next clause, under the short name vee-ess.

[c5.unwrap.3] {range} Range, from zero to the size minus one, gives the positions zero, one, two, three and four. {unwind} Unwind turns a list into rows, one row per element. {unnest} It's the same idea as un-nest, from last lecture. {rows} So now there are five rows, and in each one, the variable eye holds one position.

[c5.unwrap.4] {lookup} In each row, we look up the vertex at that position. {name} People have a name, and movies have a title. {nulls} So asking for both gives a null in every row, on one side or the other. {coalesce} The function coalesce returns the first of its arguments that is not null. {merge} So every row ends up with one value, a name or a title. {schema} We need this because there's no schema saying which properties a vertex must have.

[c5.unwrap.5] {steps} The result is a table of steps, from step zero, Jennifer Lawrence, to step four, Daniel Radcliffe. {draw} Or you can simply return the path, and the Traverse app draws it for you.

[c5.bacon.1] {game} Now, Kevin Bacon. {zero} Kevin Bacon himself has a Bacon number of zero. {one} If you've been in a film with him, your Bacon number is one. {two} Otherwise, if one of your co-stars has been in a film with him, your number is two, and so on. {erdos} Mathematicians play the same game with Paul Air-dish and shared papers, and people with a low Air-dish number like to mention it. {ask} So how many actors have each Bacon number? {pause}

[c5.bacon.2] {build} You can build the query from the shortest path one. {kevin} The start is now Kevin Bacon. {any} At the other end, delete the name, so the end can be any person at all. {allsp} Use all shortest paths, to reach everyone connected to him. {where} The where clause leaves out Kevin Bacon himself. {without} Traverse gives the same table without it.

[c5.bacon.3] {length} Now, what's the Bacon number of a path? {pause} {half} Each hop from one actor to the next takes two edges, into a movie and out again. {parity} Every step flips the side, as we saw last time. So the Bacon number is the length of the path, divided by two.

[c5.bacon.4] {count} Then we count people for each number. {why} But why count distinct person IDs, and not just rows? {pause} {every} Because all shortest paths returns every shortest path, and many people have more than one. {three} Eight thousand six hundred and thirty-one people have Bacon number three, and they're reached by over a hundred and eleven thousand shortest paths. {rows} Counting rows would count paths, not people. {group} And as in part three, the grouping is implicit, by Bacon number.

[c5.bacon.6] {six} So the name of the game is nearly right. [c5.lang.1] {cypher} Cypher was created at the company Neo four J, around twenty eleven. {open} It was later published as an open specification, called open Cypher, so other databases could use it too. {others} Other graph languages exist as well. {sparql} Sparkle works on a different graph model, called R D F, in databases known as triple stores. {gremlin} Gremlin is another.

[c5.lang.2] {iso} More recently, the standards body ISO took up the idea, and, for some reason, it standardised two graph languages. {gql} The first is G Q L, the graph query language, from twenty twenty-four. It's based largely on Cypher, and Traverse runs it too. {pgq} The second is sequel P G Q, part sixteen of the twenty twenty-three sequel standard. It adds Cypher-style patterns to sequel itself.

[c5.lang.3] {slide} Here's our shortest path query, written in G Q L. {shortest} Instead of a function, you write the keywords shortest one, in front of the pattern. {plus} And instead of a star inside the brackets, the edge is followed by a plus sign. {regex} Plus means one or more in a row, just as it does in a regular expression. {four} It returns a length of four, as before.
